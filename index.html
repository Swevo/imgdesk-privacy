ImgDesk Privacy Policy

Last updated: August 2026

ImgDesk ("the app", "we", "our") is developed by Justin Bannister. This policy explains what data the app collects and how it's used.

Summary

ImgDesk does not collect, transmit, or store any of your image content, and does not include any analytics, tracking, or advertising.

What ImgDesk does NOT do

  • It does not upload your photos or images, their pixel content, or any metadata extracted from them (including EXIF/GPS data) to any server. All image conversion, resizing, compression, and metadata stripping happens entirely on your device.
  • It does not include third-party analytics or advertising SDKs.
  • It does not require an account or sign-in to use any feature.
  • It does not access your camera, microphone, or location — image files are only read from paths you explicitly choose via the standard Windows file picker, drag-and-drop, or (Business tier) a folder you explicitly point it at to watch.

What data is stored, and where

The following data is stored locally on your device only, using Windows' standard per-app application data storage (ApplicationData.LocalSettings), and is never transmitted anywhere:

  • App preferences: selected theme (light/dark/system), last-used output format, quality, and resize settings.
  • Recent files list: file paths of recently opened images, so they can appear in the "Recent Files" menu. Only the file path is stored, not the image content.
  • Trial and purchase state: the date you first launched the app, a count of successful conversions, and whether you've been shown the Store review prompt. This is used only to manage the free trial window and avoid asking for a review more than once.
  • Business tier settings (if unlocked): your configured folder-watch path, rename pattern template, and any CLI/scripting hook configuration you set up. These stay on your device and are only used to run the automation you configured.

None of the above ever leaves your device.

Image metadata (EXIF / GPS)

ImgDesk lets you view and, optionally, strip EXIF and GPS location data embedded in a photo before you share it. This processing happens entirely on-device: ImgDesk reads the metadata already present in a file you opened, never contacts any server to look it up, and never transmits it anywhere. The choice to keep or remove this data is entirely yours.

Microsoft Store purchases

If you purchase "Pro Unlock" or the "Business" tier add-on, that transaction is handled entirely by the Microsoft Store (Windows.Services.Store API). ImgDesk only receives a yes/no answer about whether you own the add-on — it does not see your payment details, which are handled by Microsoft under the Microsoft Privacy Statement.

Store review prompts

ImgDesk may ask, at most once, whether you'd like to rate the app in the Microsoft Store. This uses the built-in StoreContext.RequestRateAndReviewAppAsync API, which is handled entirely by Windows/the Microsoft Store — ImgDesk does not see or store your response.

Permissions

ImgDesk requests only the file-system access needed to open, convert, and save the image files you choose via the standard Windows file pickers, drag-and-drop, or (Business tier only) a folder you explicitly configure for watch-and-convert automation. It does not request network, camera, microphone, location, or contacts access.

Children's privacy

ImgDesk does not knowingly collect any personal information from anyone, including children, because it does not collect personal information at all beyond the on-device preferences described above.
